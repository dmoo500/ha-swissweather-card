# Home Assistant 2025.8+ Compatibility

This SwissWeather Card is specially optimized for Home Assistant 2025.8+ and utilizes the latest features.

## New Features in HA 2025.8

### 🔄 **Modern Entity Structure**
```typescript
// The card now uses typed entities
interface WeatherEntity extends HassEntity {
  attributes: {
    temperature: number;
    temperature_unit: string;
    humidity: number;
    pressure: number;
    wind_speed: number;
    wind_bearing: number;
    forecast: WeatherForecast[];
    // ... additional attributes
  };
}
```

### 🎨 **Improved Theming Support**
The card automatically adapts to the current HA theme:

```yaml
# Lovelace configuration
type: custom:swissweather-card
entity: weather.home
theme: auto  # Automatic theme detection
```

### ⚡ **Performance Optimizations**
- **Lazy Loading** for better performance
- **TypeScript** for better type safety
- **Modern ES2022** for latest browser features
- **Tree Shaking** for smaller bundle size

## Installation for HA 2025.8+

### 1. **HACS Installation (Recommended)**
```yaml
# Add this repository to HACS
https://github.com/dmoo500/ha-swissweather-card
```

### 2. **Manual Installation**
1. Download `swissweather-card.js` from the `dist/` folder
2. Copy it to `config/www/`
3. Add the resource:
```yaml
lovelace:
  resources:
    - url: /local/swissweather-card.js
      type: module
```

## Migration from Older Versions

### 🔄 **Breaking Changes**
1. **Entity Structure**: Updated to match HA 2025.8+ entity model
2. **Theme System**: New automatic theme detection
3. **Configuration Format**: Some options renamed for clarity

### 🛠️ **Migration Steps**
1. **Backup Configuration**
   ```bash
   # Create backup of current configuration
   cp ui-lovelace.yaml ui-lovelace.yaml.backup
   ```

2. **Update Card Version**
   ```bash
   # Via HACS
   HACS → Frontend → SwissWeather Card → Update
   
   # Or download latest release
   wget https://github.com/dmoo500/ha-swissweather-card/releases/latest/download/swissweather-card.js
   ```

3. **Update Configuration**
   ```yaml
   # Old format (pre-2025.8)
   type: custom:swissweather-card
   entity: weather.home
   show_current: true
   show_forecast: true
   
   # New format (2025.8+)
   type: custom:swissweather-card  
   entity: weather.home
   display_options:
     show_current: true
     show_forecast: true
   theme_mode: auto
   ```

## Debug and Troubleshooting

### 🔍 **HA 2025.8+ Specific Issues**

#### Entity Loading Problems
```bash
# Check if entity exists in new format:
# Developer Tools → States → search for weather entities
# Verify entity has updated attribute structure
```

#### Theme Compatibility
1. Check browser console (F12)
2. Verify theme variables are loaded
3. Test with different HA themes

#### Performance Issues  
1. Enable performance monitoring:
   ```yaml
   type: custom:swissweather-card
   entity: weather.home
   debug: true
   performance_monitoring: true
   ```

### 🚨 **Common HA 2025.8+ Errors**

#### Error: "Entity not compatible"
**Solution:** Entity may not be updated for HA 2025.8+
1. Check entity attributes in Developer Tools
2. Update weather integration
3. Restart Home Assistant

#### Error: "Theme variables not found"
**Solution:** Theme system changed in HA 2025.8+
1. Update to latest HA version
2. Clear browser cache
3. Verify theme is compatible

#### Error: "Module loading failed"
**Solution:** Resource loading changed
```yaml
# Ensure correct resource configuration
lovelace:
  resources:
    - url: /local/swissweather-card.js
      type: module  # Important for HA 2025.8+
```

## Automation Examples

### 🔄 **Weather Update Automation**
```yaml
automation:
  - alias: "Update Weather Display"
    trigger:
      - platform: time_pattern
        minutes: "/15"  # Every 15 minutes
    action:
      - service: homeassistant.update_entity
        target:
          entity_id: weather.openweathermap
      - service: browser_mod.refresh
        data:
          deviceID: this
```

### ⚠️ **Weather Warning Notification**
```yaml
automation:
  - alias: "Weather Warning Alert"
    trigger:
      - platform: state
        entity_id: sensor.weather_warnings
        to: 
          - "warning"
          - "alert"
    action:
      - service: notify.mobile_app
        data:
          message: "Weather warning: {{ trigger.to_state.state }}"
          data:
            badge: 1
            importance: high
```
